A research cluster redesigned to be secure by default, for 800+ researchers

I redesigned the access architecture of a university cluster shared by hundreds of researchers, replacing legacy, unencrypted identity management and terminal-only access.

800+accounts migrated
2FAon external access
100%access config in Ansible

The problem

A university cluster shared by hundreds of researchers still relied on NIS, a legacy protocol that sends identity data unencrypted, and on terminal-only access.

What I did

I redesigned how people and services reach the cluster. Admin services moved to an isolated node reachable only with SSH keys. All user accounts moved from NIS to a 389-DS LDAP directory, with SSSD on every node. External access now requires two-factor authentication under a single password policy, and Open OnDemand with single sign-on gives researchers a way in from a web browser.

Result

Centralized, encrypted login on every node; admin services separated from user access; and a browser-based way in for researchers who don't use a terminal. Every access setting lives in Ansible playbooks, so every change is tracked and any node can be rebuilt to a known, audited state.
